## 本周核心定义

当前推荐第一版状态：

```text
s_i_f = (P_i, f)
```

其中：

```text
P_i subset F_bar:
  certified convex region

f in If = {triangle, line}:
  formation template

z_i_f = formation(P_i,f):
  formation f 在 P_i 中的最优摆放
```

安全条件：

```text
E(z_i_f,f) subset P_i subset F_bar
```

其中：

```text
V(z,f):
  transformed outer vertices

E(z,f) = conv(V(z,f)):
  formation envelope
```

## 和 IJRR 2017 的关系

IJRR 原文更接近：

```text
formation_best(P)
returns one best result:
  (z*, f*)
```

当前项目为了构造 DFTS，需要保留所有可行 formation label，所以扩展成：

```text
formation(P_i,f)
fixes f and returns best z for this f
```

然后定义：

```text
Allowed(P_i) =
  { f | formation(P_i,f) is not empty }

Form(P_i) =
  { (z_i_f,f) | f in Allowed(P_i) }
```

这不是否定原文，而是把 IJRR 的优化模块拆开，用于构造多 formation 的离散状态空间。

## Edge / Transition 的最终理解

IJRR 4.1 的关键结构是：

```text
L_P = all states/configurations contained in P
```

一条 edge 写作：

```text
e = (s_a, s_b, P_e)
```

成立条件：

```text
s_a in L_Pe
s_b in L_Pe
P_e subset F_bar
```

展开为：

```text
E(z_a,f_a) subset P_e
E(z_b,f_b) subset P_e
P_e subset F_bar
```

所以 edge 不是普通相邻关系，而是带有 convex safety certificate 的 transition。

## Bridge 的最终理解

对两个 convex regions：

```text
P_i, P_j
```

先看交集：

```text
P_c = P_i cap P_j
```

但不是 `P_c` 非空就能连。必须检查：

```text
z_c = formation(P_c, f_c)
E(z_c,f_c) subset P_c
```

若可行，生成 bridge state：

```text
s_c = (P_c, f_c)
```

因为：

```text
P_c subset P_i
P_c subset P_j
```

所以：

```text
s_c in L_Pi
s_c in L_Pj
```

然后用 `P_i` 或 `P_j` 作为 edge certificate 建边。
